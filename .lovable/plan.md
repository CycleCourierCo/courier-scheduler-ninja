# Website (Shopify) vs portal theme

## Comparison

| | Website (cyclecourierco.com) | Portal |
|---|---|---|
| Page background | #F2F2EC paper | same (within 1 shade) |
| Main text | #1C2421 | same (within 1 shade) |
| Brand green | #4D6863 | same |
| Cards | white | white |
| Lines | #DCDED6 | very close |
| Grey text | #5A6662 | slightly lighter grey |
| Red | #C22F2E | slightly more orange-red |
| Highlight colour | yellow #F5B800 | amber |
| Main font | **Overpass** (headings extra bold) | **Hanken Grotesk** |
| Number font | **Overpass Mono** | **DM Mono** |
| Corners | buttons/boxes 6px, cards 8px | 10px on everything |

The colours already match. The differences are the fonts, the slightly rounder corners, the yellow and the red.

## Design style

**Shared by both:**
- flat design with no shadows or gradients
- thin lines between sections
- a white card on a cream page
- green as the main action colour
- numbers and references in a typewriter-style font

**Where they differ:**

| | Website | Portal |
|---|---|---|
| Headings | Big, extra-bold, short sentences ("Racked upright, never boxed") | Smaller and more functional |
| Small labels | CAPITALS with wide letter spacing above headings | Mostly normal case |
| Buttons | Tall (48px, 56px for large), green / dark / outline only | Mostly 40px, more button types |
| Key panels | "Slip" cards overlapping the banner (e.g. Get your price) | Plain cards and lists |
| Steps | Numbered route steps ("How it works") | Strip map of the bike's journey (same idea, different look) |
| Spacing | Roomy marketing layout | Dense working screens |

The portal and the website feel like the same brand. The website reads as a marketing site and the portal as a work tool, which suits each job.

## Proposed change (only if you want them to match)

1. Change the portal fonts to Overpass and Overpass Mono, with extra bold headings.
2. Use 6px corners on buttons and boxes and 8px on cards.
3. Use the website's yellow, red and grey text.
4. On customer-facing pages only (tracking, availability, repair offers, ETA): use the website's extra-bold headings, capital-letter labels and tall green/dark/outline buttons. Staff screens stay compact.
5. Leave dark mode, labels and emails as they are. Emails would keep their current fonts.

## Technical details
- Change only the theme settings and the font import; no page-by-page edits.
- Afterwards, check that the 48px floor-screen controls and the label PDFs still look right.
